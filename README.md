# Cinnabar Lab - Support

Cinnabar Lab is your ultimate Pokémon companion app for iOS.

## Features

- **Complete Pokédex** - Browse all Pokémon with detailed stats and information
- **Pokémon Quiz** - Test your knowledge across all generations
- **Living Dex Tracker** - Track your collection progress
- **Team Builder** - Build teams with type coverage analysis
- **Completely Offline** - No internet required
